# Erhun Etiket: Sürümler

Bu depo yalnızca **Erhun Etiket** programının kurulum ve güncelleme dosyalarını içerir. Kaynak kod ayrı ve gizlidir.

## Kurulum

1. [**Sürümler**](../../releases/latest) sayfasını açın.
2. **Assets** bölümünden `Erhun-Etiket-Kurulum-vX.X.X.exe` dosyasını indirin ve çift tıklayın.
   Windows "Windows bilgisayarınızı korudu" derse: **Daha fazla bilgi → Yine de çalıştır**.
3. Program ilk açılışta **30 gün deneme** olarak çalışır. Lisans anahtarı, sağ üstteki **anahtar simgesinden** girilir.

Kurulumdan sonra program yeni sürümleri kendiliğinden bulur ve "Şimdi güncelle" ile günceller.
Ürün listesi ve resimler güncellemede korunur.

## Dosyalar

| Dosya | Ne için |
| --- | --- |
| `Erhun-Etiket-Kurulum-v….exe` | Yeni bilgisayara kurulum (yönetici izni gerekmez) |
| `Erhun-Etiket-v…-Tasinabilir.zip` | Kurulumsuz, klasörden çalışan sürüm |
| `Guncelleme-Paketi-v….zip` | Eski sürümleri elle güncellemek için |
| `app.asar`, `manifest.json` | Programın otomatik güncelleme dosyaları (elle kullanılmaz) |
